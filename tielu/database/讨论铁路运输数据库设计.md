# 多式联运表说明（全部中文字段）

你这边 **陆运已经五流合一**。下面这套表的定位是：

- **不要再造一套货主、发货单、应收应付**（用你们陆运现成的）。  
- **补上铁路段**：货物运单、箱号、篷布，以及「发端汽车 / 火车 / 收端汽车」怎么和箱对上。  
- 陆运里的「一趟车」= 这里的 **汽车趟次**；两端短驳可以直接复用陆运派车，只要挂上 **集装箱编号**。

库里的英文字段名写在括号里，方便对程序；业务上请一律按中文理解。

每张表都有 **主键：编号**（库字段 `id`，UUID）。

---

## 和陆运系统怎么接

| 陆运已有（五流） | 本铁路扩展怎么挂 |
|------------------|-------------------|
| 货主 | 铁路委托上的 **货主编号** 填陆运货主主键 |
| 运输订单 / 发货单 | 铁路 **发货指令编号** 或直接填陆运发货单号 |
| 陆运运单 / 派车 | **汽车趟次**，`路段` 填发端或收端 |
| 应收应付核销 | 继续用陆运财务；铁路运费进 **应付（铁路）**，可按大票号对账 |
| 节点轨迹 | 铁路节点写入 **收发流水**，或回写陆运轨迹 |

铁路侧真正新增、陆运通常没有的是：**铁路货物运单、集装箱、篷布**。

---

## 总关联（中文）

```
货主
 └── 运输委托（万吨级、可多日）
       ├── 发货指令（可对接陆运发货单）
       │     ├── 每日发货计划
       │     └── 发货实绩（一箱从发出到签收）
       ├── 铁路批次
       ├── 铁路货物运单 ── 集装箱
       │         ├── 箱与汽车关系 ── 汽车趟次（发端/收端，可对接陆运派车）
       │         └── 篷布使用 ── 篷布档案
       ├── 单证台账
       └── 应收 / 应付 / 收付款 / 核销（若与陆运财务并存，建议只记铁路差价或只做对账码）
```

## 接入陆运时建议最小铁路集

陆运已有货主、派车、财务的，铁路侧最少落地：

1. **铁路货物运单**  
2. **集装箱**  
3. **箱与汽车关系**（汽车趟次编号填陆运派车主键）  
4. **篷布档案 + 篷布使用**（有篷布时）  
5. **发货实绩**（箱挂到陆运发货单号 / 本库发货指令）

其余委托、应收、车辆档案能映射就不重复建。
